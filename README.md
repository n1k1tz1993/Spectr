# Спектр

Веб-игра в одном файле: `index.html` (он же `Web/spektr.html`). Открывается в браузере и на GitHub Pages.

Сейчас реализовано:
- регионы (5), по 15 действий в каждом, 20 общих действий, в ход набор из 3 случайных;
- действия: бонусы и эффекты силы, случайные, условные (подкаст), джетлаг при перелёте;
- библиотека, отдых, местный турнир (3 уровня), бюро: бой с про-игроком и лестничный матч на рейтинг;
- пропуск хода, перелёт, коллекция трофеев;
- сила скрыта, показывается только рейтинг.

Ещё не сделано: лиги и матчи по расписанию, драфт, чемпионат мира, Wild Card, медали региона, верхняя панель с аватаркой и флагом из ассетов, тексты действий (сейчас «Текст будет задан.»).
